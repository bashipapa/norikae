# のりかえアラーム（norikae）

荒井（山陽電車）→ 新開地 → 北鈴蘭台（神戸電鉄）の帰り道で、**寝過ごして降り損ねる**のを防ぐ個人用の Android アプリ。

- 21時以降に電車に乗ったら「飲み会モード」として自動でアラームを入れる
- 新開地（乗り換え）と北鈴蘭台（降車）の2か所で、予告 → 本アラーム → 降りたかの確認
- 降りていなさそうなら、追加のアラームを1分おきに最大5回鳴らす
- 普通電車を優先して経路を選ぶ（直通特急は乗り過ごすと梅田まで行くため）
- 時刻表から帰り道の候補を出し、選んでアラームを設定できる

## 構成

```
norikae/
├─ data/timetable.json   時刻表（21時以降〜終電）。アプリに同梱される
├─ core/                 純Kotlinのロジック（Android非依存・単体テストあり）
│   ├─ ServiceTime.kt    営業日基準の時刻（24:03 など）、平日/土休日、飲み会モード判定
│   ├─ Timetable.kt      時刻表の読み込み
│   ├─ RoutePlanner.kt   経路の組み立て・普通優先のおすすめ・実際の乗車時刻からの推定
│   ├─ AlarmPlanner.kt   アラーム時刻の計算
│   ├─ TripEngine.kt     乗車中の状態遷移（乗り過ごし・粟生線の判定）
│   └─ Geo.kt            駅の位置と距離
└─ app/                  Androidアプリ（Kotlin / Jetpack Compose）
    ├─ MainActivity.kt   帰り道の候補一覧・権限・設定・駅の位置登録
    ├─ TripController.kt core の判定結果を Android の機能で実行
    ├─ AlarmScheduler.kt AlarmManager.setAlarmClock で予約
    ├─ Ringer.kt         アラーム音＋全画面表示、案内通知
    ├─ RingingActivity.kt ロック画面上の鳴動画面
    ├─ TripService.kt    乗車中だけ位置を取る常駐処理
    ├─ Sensing.kt        乗り物/歩行の判定・荒井のジオフェンスの登録
    └─ Receivers.kt      アラーム・乗り物/歩行・ジオフェンス・再起動の受信
```

### 判定の流れ

```
待機
 └ 荒井の範囲を出た ＋ 乗り物での移動を検知 ＋ 21時以降 → 自動開始（手動でも開始できる）
     山陽に乗車中 ──(新開地: 予告 / 本アラーム / 到着+2分で確認)──→
       ├ 新開地付近で歩行を検知 → 乗り換え中
       │    └ 乗り物での移動を検知 → 神戸電鉄に乗車中（実際に乗った電車に合わせてアラームを調整）
       │         ├ 北鈴蘭台で歩行・停止 → 完了
       │         ├ 到着+2分でまだ乗っている／山の街に近づいた → 乗り過ごし警報＋戻る電車の案内
       │         └ 粟生線の電車に乗った／鈴蘭台西口に近づいた → 「電車が違う」警報
       └ 到着+2分でまだ乗っている → 乗り過ごし警報（1分おき最大5回）
```

新開地付近は地下で GPS が当てにならないため、新開地では「乗り物 → 歩行」の切り替わりを主な手がかりにしている。

## 時刻表データ（data/timetable.json）

| 区間 | 状態 | 出典 |
|---|---|---|
| 神戸電鉄 新開地発（21時〜終電） | 入力済み（2025年3月15日改正） | 神戸電鉄 公式 [新開地駅時刻表PDF](https://www.shintetsu.co.jp/cms/wp-content/uploads/station-docs/20250315/shinkaichi-timetable.pdf) |
| 神戸電鉄 北鈴蘭台着 | 入力済み（北鈴蘭台駅の有馬・三田方面の発車時刻を着時刻とみなす） | 神戸電鉄 公式 [北鈴蘭台駅時刻表PDF](https://www.shintetsu.co.jp/cms/wp-content/uploads/station-docs/20250315/kita_suzurandai-timetable.pdf) |
| 北鈴蘭台発 新開地方面（乗り過ごし時の戻り案内） | 入力済み | 同上 |
| 山陽 荒井発（乗り換え込みの新開地着） | **ローカルファイル** `data/local/sanyo.json`（git管理外） | Yahoo!路線情報（下記参照） |

- 粟生線の電車（志染・小野・粟生・三木・西鈴蘭台行き）と鈴蘭台止まり（24:03）は北鈴蘭台に行かないので `kitaSuzurandai: null`
- 23:34 三木行き（準急）は鈴蘭台で三田行きに接続するため、北鈴蘭台 23:50着として扱う
- `data/local/sanyo.json` が無いときは、アプリの設定「荒井→新開地の所要分」と乗車時刻から新開地着を推定する

### 山陽（荒井発）のローカルファイル

山陽の時刻は Yahoo!路線情報から取得した。Yahoo!路線情報の時刻データには転載・複写を禁じる記載があるため、**公開リポジトリにはコミットせず**、`data/local/sanyo.json`（`.gitignore` 済み）に置く。ビルド時に `assets/local/sanyo.json` としてアプリに同梱され、アプリが読み込む。

- 新開地まで行かない列車（山陽明石・東須磨・東二見行き）は、終点で乗り換える次の電車を調べて「乗り換え後の新開地着」を入れている
- 乗り換え先が直通特急・特急の場合は `transferTrainType` に入る。乗り過ごすと梅田まで行くので「梅田注意」扱いになり、普通優先のおすすめから外れやすくなる
- 終電後（新開地に着いても北鈴蘭台行きが無い列車）は候補に出ない

形式は次のとおり。

```json
"sanyo": {
  "weekday": [
    { "dep": "21:32", "type": "普通", "dest": "神戸三宮", "shinkaichi": "22:40" },
    { "dep": "22:04", "type": "普通", "dest": "東須磨", "shinkaichi": "23:10", "transferAt": "東須磨",
      "transferTrainType": "直通特急", "transferTrainDest": "大阪梅田(阪神線)",
      "transferNote": "東須磨 23:00着 → 23:02発 直通特急 大阪梅田行きに乗り換え" }
  ],
  "holiday": []
}
```

（上の時刻は形式の例で、実際の時刻ではない）

- `shinkaichi`: 新開地着。途中で乗り換えが必要な列車は、乗り換え後の新開地着
- `transferAt`: 途中の乗り換え駅（新開地まで行かない列車のとき）
- `transferTrainType` / `transferTrainDest` / `transferNote`: 乗り換え先の列車の種別・行先・説明
- `type`: `普通` / `直通特急` / `S特急` など。普通以外は「梅田注意」として新開地の予告を早める

## ビルド

- `core`（ロジック）は JDK だけでビルド・テストできる
  ```
  ./gradlew :core:test
  ```
- `app` は Android SDK が必要。Android Studio でこのフォルダを開くと `local.properties` に SDK の場所が書かれ、`app` モジュールが読み込まれる（`settings.gradle.kts` で SDK があるときだけ読み込む設定にしている）
  ```
  ./gradlew :app:installDebug
  ```

## 初回の設定（アプリ内）

1. 権限を許可する：位置情報（「常に許可」）、身体活動（乗り物/歩行の判定）、通知、全画面表示、正確なアラーム
2. 「荒井→新開地の所要分」を設定する（山陽の時刻表を入力するまでの暫定）
3. 各駅にいるときに「今いる場所を登録」を押す
   - 荒井：自動開始（荒井の範囲を出たのを検知）に必要
   - 北鈴蘭台：降りたかの判定が正確になる
   - 山の街・鈴蘭台西口：乗り過ごし・粟生線の検知に使う
4. 祝日は自動で判定しないので、画面上部で「土休日ダイヤ」に切り替える

## 未確認・今後

- `app` モジュールは Android SDK のない環境で書いたため、まだ一度もビルドしていない。Android Studio で最初にビルドしたときにエラーが出る可能性がある
- 乗り物/歩行の判定が OS から届くまでの遅れ、地下での位置の取れ方は実機で確かめて、判定のしきい値（新開地の到着5分前から歩行を有効とする、など）を調整する
- 途中駅で後ろから来る直通特急に乗り換えると早く着くケース（例：普通で東二見まで行き直通特急に乗り換え）は、終点での乗り換えしか計算していない
- ダイヤ改正時は `data/local/sanyo.json` と神戸電鉄の時刻を取り直す
