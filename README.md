# のりかえアラーム（norikae）

全体構成の1枚資料：[docs/norikae-architecture.pptx](docs/norikae-architecture.pptx)（A4横）

荒井・山陽明石（山陽電車）→ 新開地 → 北鈴蘭台（神戸電鉄）の**平日の**帰り道で、寝過ごして降り損ねるのを防ぐ個人用の Android アプリ。

- 平日の21時以降に荒井から電車に乗ったら「飲み会モード」として自動でアラームを入れる
- 新開地（乗り換え）と北鈴蘭台（降車）の2か所で、予告 → 本アラーム → 降りたかの確認
- 降りていなさそうなら、追加のアラームを1分おきに最大5回鳴らす
- 普通電車を優先して経路を選ぶ（直通特急は乗り過ごすと梅田まで行くため）
- 時刻表から帰り道の候補を出し、選んでアラームを設定できる。乗る駅は「荒井（普通）」「荒井（特急）」「明石（普通）」「明石（特急）」のタブで切り替え。荒井（特急）は夕方 16:57〜20:24 の直通特急・S特急、荒井（普通）は21時以降、明石は21時から（「今乗った」は時間帯に関係なく乗った時刻の列車に合わせる）
- **事前に予定を入れる**：出発まで15分以上ある電車をタップすると「予定」として入り、出発の15分前に「帰る時間です」のアラームで段取り（出発時刻・乗り換え・着く時刻・所要時間、会計・忘れ物・駅へ移動）を知らせる。出発時刻になったら自動で乗車中に切り替わる。位置の取得は15分前のお知らせから始める（電池のため）。駅までの移動中の歩行や乗り物は判定に使わない
- 各候補に合計の所要時間（乗る駅を出てから北鈴蘭台に着くまで）と新開地の乗り換え時間を表示。所要時間が一番短い候補は緑で「最短」
- 「乗り過ごすと梅田まで行きます」の警告（と新開地の予告を8分前に早める処理）は、21時以降に出る電車だけ
- 新開地の乗り換えは最短1分（走る前提）で計算。2分以内の乗り換えはオレンジで目立たせ、新開地の本アラームでも「乗り換え◯分、走って！」と知らせる
- 北鈴蘭台行きの終電後も、新開地 24:03 の鈴蘭台止まりに間に合う電車は「鈴蘭台からタクシー」の候補として出す（終点の鈴蘭台で起こす）
- 土日は動かない。祝日は右上の設定（⚙）の「今日は休み」で止める
- 右上の設定（⚙）に、平日・休みの設定、アラームのテスト、荒井→新開地の所要分、駅の位置をまとめている

## インストール（Android）

1. スマホのブラウザで **https://github.com/bashipapa/norikae/releases/tag/latest** を開く
2. `norikae.apk` をタップしてダウンロード
3. ダウンロードした APK を開く。「この提供元のアプリを許可」を求められたら、ブラウザ（Chrome など）に許可してインストール
4. Play プロテクトの警告が出たら「インストールする」を選ぶ（個人用アプリで Play ストアを通していないため）
5. アプリを開き、画面上部の「権限の設定」を許可する
   - 位置情報（「使用中のみ」で可）、身体活動（乗り物/歩行の判定）、通知、全画面表示、正確なアラーム
   - 荒井を出たら自動で始める機能を使うときだけ、位置情報を「常に許可」にする
6. 右上の設定（⚙）→「アラームのテスト」→「1分後に鳴らす」を押して画面を消し、ロック中に鳴るか確かめる
7. 電池の最適化でアプリが止められないよう、設定 → アプリ → のりかえアラーム → 電池 →「制限なし」にしておく

## アラームの鳴らし方

- **予約**：OS の目覚まし機能（`AlarmManager.setAlarmClock`）。スリープ中でも時刻どおりに動き、アプリを閉じても予約は OS が持っている
- **音と振動**：通知ではなく**アプリ自身**が「アラーム」の用途で出す（通知のクールダウンや通知の音の設定に左右されにくくするため。2026-11-13 に起きられなかった件の対策）
  - 音を出すときは**アラーム音量を最大**にし、止めたら元に戻す
  - **最大の強さの振動**を途切れず続ける
  - **新開地に着くまで（出発15分前のお知らせ・新開地の予告・起こし直し・本アラーム）は振動だけ**（音を出さない・音量も変えない）
  - 新開地に着いてから（新開地の乗り過ごし警報・北鈴蘭台のアラーム・電車違い）は端末のアラーム音。**乗り過ごし警報が10回を超えても乗ったまま（11回目から）だけサイレン**
- **だんだん強く**：予告（新開地の5分前、梅田まで行く電車は8分前／北鈴蘭台の5分前）のあと、「起きた（止める）」を押すまで本アラームまで1分おきに鳴らし直す
- **画面**：ロック中も画面を点けて全画面の鳴動画面を出す。最長5分で自動停止（鳴らし直すたびに延びる）
- 設定（⚙）→「アラームのテスト」の「サイレン」で、乗り過ごし警報が10回を超えたときの音を確かめられる

## 権限と、アプリを開いておく必要があるか

アプリを開いたままにする必要はない（閉じても画面を消しても動く）。

| 位置情報の権限 | 画面から開始（「この電車で設定」「今乗った」） | 自動開始（荒井を出たら） |
|---|---|---|
| 使用中のみ許可 | ○ アラーム・乗り物/歩行の判定・位置による乗り過ごし判定がすべて動く | × 使えない |
| 常に許可 | ○ | ○ |

- 画面から開始すると、乗車中の常駐処理（通知が出たままになる）が位置を取り続ける
- Android 10 以降、ジオフェンス（荒井を出た検知）には「常に許可」が必要
- Android 14 以降、アプリが裏にいるときに位置の常駐処理を始めるには「常に許可」が必要。無い場合、位置を使わずにアラームと乗り物/歩行の判定だけで動く

`main` にプッシュするたびに GitHub Actions がビルドし、Releases の `latest` が新しい APK に置き換わる。署名鍵を固定しているので、新しい APK はアンインストールせずに上書きインストールできる。

## 乗車ログ

設定（⚙）→「乗車ログを見る」で、アプリが何を検知・判定し、何を鳴らしたかを日付ごとに確認できる。右上の共有ボタンで直近7日分をテキストで送れる。端末の外には自動で送らない。

記録するもの：
- 開始（一覧から選択／今乗った／自動開始）と経路、予約したアラームの時刻
- 21時以降に乗り物を検知したのに自動開始しなかった理由（土日・休み、駅の範囲を出た記録が無い、出てから15分以上たっている）
- 荒井・山陽明石の範囲を出たこと、乗車中の乗り物/歩行/停止の検知、乗車中の位置（2分に1回、一番近い駅までの距離）
- 状態の変化（山陽に乗車中 → 新開地で乗り換え中 など）、予約したアラームの時刻になったこと、鳴らしたアラーム、出した通知
- 「止める」「降りた」などの操作、再起動、時刻表の更新

## 時刻表の自動更新（週1回）

1. **GitHub 側**：毎週月曜 3:17（日本時間）に GitHub Actions（`.github/workflows/update-timetable.yml`）が `tools/update_timetable.py` を動かし、Yahoo!路線情報から平日の時刻表を作り直す
   - 変わっていれば `data/timetable.json` をコミットし、APK もビルドし直して Releases に置く
   - 変わっていなくても `data/timetable-checked.json`（確認した日）をコミットする。公開リポジトリは60日間活動が無いと定期実行が止まるため
   - 取得結果がおかしい（本数が前回の半分未満など）ときは書き換えずに失敗で終わる（GitHub からメールが届く）
   - 手動で動かすとき：GitHub の Actions →「Update timetable (weekly)」→「Run workflow」
2. **スマホ側**：アプリが週1回 GitHub の `data/timetable.json` をダウンロードして保存する（WorkManager）。APK を入れ直さなくても新しい時刻表で動く。変わったときは通知が出る。設定（⚙）の「時刻表」で取得日の確認と「今すぐ確認する」ができる

## Fitbit Air の補助（手動）

Fitbit Air はスマホの通知を転送できず、ほかのアプリから振動アラームを入れる公式の方法も無い。そこで、アラームを設定したときに「Google Health アプリで Fitbit Air に入れる時刻」（新開地の予告・北鈴蘭台の予告と同じ時刻）を通知で知らせ、Google Health を開くボタンを付けている。設定（⚙）で止められる。

## 電車に乗ったかの判定

| 何を判定するか | 使うもの |
|---|---|
| 荒井を出た | ジオフェンス（荒井駅の半径300m）から出たことを OS が通知 |
| （共通） | 駅の位置は Yahoo!路線情報の各駅の位置を初期値として同梱。ずれるときだけアプリで「今いる場所で上書き」 |
| 電車に乗った／降りた | Activity Recognition（スマホの加速度などから OS が「乗り物」「歩行」「停止」を判定し、切り替わりを通知） |
| どの電車に乗ったか | 乗り物の判定が来た時刻を時刻表に当てはめる（予定と違う電車でもアラームを合わせ直す） |
| 乗り過ごし・粟生線 | 乗車中だけ20秒ごとに位置を取得（地下の新開地でも取れることを確認）。取ってから3分以内の位置だけ使う。駅から250m 以内なら「その駅にいる」、次の駅（新開地なら高速神戸、北鈴蘭台なら山の街）の方が近ければ「乗り過ごし」、それ以外は「まだ手前（遅れ）」として1分後に確認し直す。位置が取れないときだけ、歩行を検知できたかで判断する（安全のため鳴らす側に倒す） |
| 乗り過ごしたあと | 電車に乗っている限り1分おきに鳴らし続ける（回数の上限なし。「止める」は今鳴っている1回分だけ止まる）。止まるのは、歩行を検知したとき、同じ場所（150m以内）に5分以上とどまって乗り物の判定でないとき（次の駅で降りて待っている）、新開地にいると分かったとき、ボタンを押したとき |
| 誤判定の修正 | 新開地にいると分かった時点で自動で「乗り換え中」に戻す。警報画面と乗車中の欄の「新開地で乗り換え中」ボタンでも戻せる。北鈴蘭台のアラームは新開地の判定に関係なく鳴る |

自動開始の条件：**平日** ＋ **21時以降** ＋ **荒井または山陽明石の範囲を出てから15分以内** ＋ **「乗り物」の判定**。明石から自動開始したときは、乗った時刻に一番近い列車（特急・普通を問わず）に合わせる。

## 構成

```
norikae/
├─ data/timetable.json   平日の時刻表（21時以降〜終電）。アプリに同梱される
├─ core/                 純Kotlinのロジック（Android非依存・単体テストあり）
│   ├─ ServiceTime.kt    営業日基準の時刻（24:03 など）、平日判定、飲み会モード判定
│   ├─ Timetable.kt      時刻表の読み込み
│   ├─ RoutePlanner.kt   経路の組み立て・普通優先のおすすめ・実際の乗車時刻からの推定
│   ├─ AlarmPlanner.kt   アラーム時刻の計算
│   ├─ TripEngine.kt     乗車中の状態遷移（乗り過ごし・粟生線の判定）
│   └─ Geo.kt            駅の位置と距離
├─ app/                  Androidアプリ（Kotlin / Jetpack Compose）
│   ├─ MainActivity.kt   帰り道の候補一覧・権限・設定・駅の位置登録
│   ├─ TripController.kt core の判定結果を Android の機能で実行
│   ├─ AlarmScheduler.kt AlarmManager.setAlarmClock で予約
│   ├─ Ringer.kt         アラーム音＋全画面表示、案内通知
│   ├─ RingingActivity.kt ロック画面上の鳴動画面
│   ├─ TripService.kt    乗車中だけ位置を取る常駐処理
│   ├─ Sensing.kt        乗り物/歩行の判定・荒井のジオフェンスの登録
│   └─ Receivers.kt      アラーム・乗り物/歩行・ジオフェンス・再起動の受信
└─ .github/workflows/build.yml  テスト → APK ビルド → Releases に公開
```

### 判定の流れ

```
待機
 └ 平日・21時以降・荒井の範囲を出た ＋ 乗り物での移動を検知 → 自動開始（手動でも開始できる）
     山陽に乗車中 ──(新開地: 予告 / 本アラーム / 到着+2分で確認)──→
       ├ 新開地付近で歩行を検知 → 乗り換え中
       │    └ 乗り物での移動を検知 → 神戸電鉄に乗車中（実際に乗った電車に合わせてアラームを調整）
       │         ├ 北鈴蘭台で歩行・停止 → 完了
       │         ├ 到着+2分でまだ乗っている／山の街に近づいた → 乗り過ごし警報＋戻る電車の案内
       │         └ 粟生線の電車に乗った／鈴蘭台西口に近づいた → 「電車が違う」警報
       └ 到着+2分でまだ乗っている → 乗り過ごし警報（1分おき最大5回）
```

| 区間 | 出典 |
|---|---|
| 山陽 荒井発（乗り換え込みの新開地着） | [Yahoo!路線情報 荒井駅](https://transit.yahoo.co.jp/timetable/26264/5920)の各列車の停車駅一覧（2026-11-09 取得） |
| 山陽 山陽明石発（同上） | [Yahoo!路線情報 山陽明石駅](https://transit.yahoo.co.jp/timetable/26377/5920)の各列車の停車駅一覧（2026-11-09 取得） |
| 神戸電鉄 24:03 鈴蘭台止まりの鈴蘭台着（24:17） | [Yahoo!路線情報 新開地駅（神戸電鉄）](https://transit.yahoo.co.jp/timetable/26399/5771)の列車の停車駅一覧 |
| 神戸電鉄 新開地発・北鈴蘭台着 | 神戸電鉄 公式 [新開地駅](https://www.shintetsu.co.jp/cms/wp-content/uploads/station-docs/20250315/shinkaichi-timetable.pdf)・[北鈴蘭台駅](https://www.shintetsu.co.jp/cms/wp-content/uploads/station-docs/20250315/kita_suzurandai-timetable.pdf)（2025-03-15 改正） |
| 北鈴蘭台発 新開地方面（乗り過ごし時の戻り案内） | 同上 |

- 新開地まで行かない列車（山陽明石・東須磨・東二見行き）は、終点で乗り換える次の電車の新開地着を入れている。乗り換え先が直通特急・特急なら「梅田注意」
- 粟生線の電車と鈴蘭台止まり（24:03）は北鈴蘭台に行かないので `kitaSuzurandai: null`
- 北鈴蘭台まで電車で帰れる最終：荒井 22:33（東二見で直通特急に乗り換え → 北鈴蘭台 23:50着）、明石（特急）23:01、明石（普通）23:04
- 鈴蘭台止まり（24:03 → 鈴蘭台 24:17着 → タクシー）に間に合う最終：荒井 22:47、明石（特急）23:33、明石（普通）23:22

## ビルド（開発者向け）

- `./gradlew :core:test` … ロジックのテスト（JDK だけで動く）
- `./gradlew :app:assembleDebug` … APK（Android SDK が必要。`settings.gradle.kts` で SDK があるときだけ `app` を読み込む）
